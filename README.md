# LLM Evaluation – Hallucination Detection & RLHF 🤖

## Overview

Today I learned two important concepts in AI/LLM evaluation:

* Hallucination Detection
* RLHF (Reinforcement Learning from Human Feedback)

## What I Learned

### 🔍 Hallucination Detection

* Identifying false or unsupported AI-generated information
* Checking factual claims against reliable evidence
* Distinguishing factual errors from hallucinated information
* Evaluating whether responses are supported by available evidence
* Writing evidence-based justifications

### 🤖 RLHF & Human Feedback

* Understanding Reinforcement Learning from Human Feedback
* How human evaluations can provide feedback for AI models
* Preference ranking between AI-generated responses
* Using structured evaluation criteria
* Understanding the role of human feedback in improving AI responses

## Practical Learning

I practiced comparing AI responses, identifying factual issues, checking instruction following, and selecting the preferred response with an evidence-based justification.

## Key Takeaway

An AI response should not only sound correct. It should be **factually accurate, supported by evidence, follow instructions, and provide useful information**.
